# Mino and the Legendary Bingsu

A short top-down RPG in English. Mino runs a bingsu shop, and Granny Kkotbun flips the table at every bowl that is not the right one. It takes about 10 minutes.

The game is written directly as RGSS3 scripts and runs on [mkxp-z](https://github.com/mkxp-z/mkxp-z). It needs no RTP or other files.

## Download

[mino-bingsu.zip](https://github.com/dominofall/mino-bingsu/releases/download/v1/mino-bingsu.zip)

## Controls

| Gamepad | Keyboard | Action |
|---|---|---|
| D-pad | Arrow keys | Move, choose |
| A | Z | Talk, confirm |
| B | X | Menu, cancel |
| X (hold) | Shift (hold) | Dash |
